**Title:** PasswordGuard: An Experimental Analysis of Password Strength and Authentication Security  
**Author:** Student Research Team  
**Course:** English Writing and Presentation Skills  

### Abstract
Password-based authentication remains the foundational access control mechanism across modern computing systems despite severe vulnerabilities stemming from human cognitive memory limits and predictable pattern selection. This paper presents PasswordGuard, an educational client-side web application designed to evaluate credential complexity, estimate theoretical search spaces, and demonstrate cryptographic hashing and salting mechanics without server-side data persistence. The system implements a transparent 0–100 heuristic scoring algorithm, theoretical character-space entropy estimation under an idealized uniform-selection assumption, and illustrative brute-force guessing projections across assumed threat models. To evaluate the functional behavior of the heuristic analyzer, an experiment was conducted on a controlled dataset of 150 synthetic passwords evenly partitioned across five structural categories ($n = 30$). The evaluation demonstrated consistent heuristic responses: 16-character pseudo-random strings (Category E) attained the highest mean score (90.0/100, 100% Strong), and multi-word passphrases (Category D) achieved the highest mean theoretical character-space entropy estimate (182.9 bits, 70.0% Strong) despite using only two character pools. Conversely, superficially complex passwords containing dictionary roots and appended symbols (Category B) were penalized heavily, averaging 10.5/100 (96.7% Weak). Because the experiment evaluates the application's internal heuristic model on synthetic samples, it does not serve as an independent real-world cracking benchmark. Ultimately, the project demonstrates that password length exponentially expands theoretical search spaces and emphasizes that effective authentication requires defense in depth, combining memorable passphrases with password managers, slow memory-hard key derivation functions such as Argon2id, rate limiting, and multi-factor authentication.

**Keywords:** password authentication; password strength; heuristic scoring; theoretical entropy; cryptographic salting
